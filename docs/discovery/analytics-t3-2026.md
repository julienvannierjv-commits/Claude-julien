- Une date de départ est renseignée dans 47 % des recherches.

## Panier

- Taux d'abandon du panier : **68 %** (ajout sans clic sur « Réserver »).
- **23 %** des paniers contiennent plusieurs fois la même destination.
- Nombre moyen de voyageurs saisi dans la recherche : **2,7**.
- Code promo saisi dans 9 % des paniers ; ESCALE10 utilisé **plus d'une fois** dans 31 % de ces cas.
